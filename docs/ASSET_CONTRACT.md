# Asset Contract — Duramax LLY Engine Lab

Status: **Written in Milestone 0, proven in Milestone 2, extended in Milestone 8 (scene-placed class) and Milestone 10 (project-frame shell class)** · Governing plan: [`docs/PLAN.md`](./PLAN.md) · Decisions: [`docs/DECISIONS.md`](./DECISIONS.md) D-011, D-038, D-041, D-042

Every model and every dimension follows one written contract. Better data later should be a one-line config change, not a rework.

## Contract Rules

- **Frame:** The concept set's frame is the master. Origin is the crank axis at the rear block / adapter plane; `+X` toward the front accessory drive, `+Y` vehicle left (LH), `+Z` up.
- **Axis conversion (Z-up → Y-up):** glTF is Y-up. Conversion happens once, at export, using the Blender glTF exporter's Y-up option. A reference fixture (a known 3-axis marker) is checked by a test.
- **Units:** Meters in models and in the math core; the config may record source values in mm or inches, converted on load.
- **Pivots and code-driven motion:** Every moving part's origin sits exactly on its rotation or slide axis. Code moves parts; Blender animation is not used.
- **Naming:** `<system>_<part>_<instance>_<variant>`, e.g. `rot_piston_c3_stock`, with cylinder numbers per the RH `1-3-5-7` / LH `2-4-6-8` scheme (see scene-placed root-object and project-frame shell `extras.partId` rules below).
- **Budgets:** Triangle, draw-call, and texture-memory limits per tier, set at Milestone 2 from measurements.
- **Compression:** meshopt or Draco for geometry, KTX2 for textures (deferred across M2–M10 because uncompressed payloads already sit comfortably inside every D-033 budget).
- **Provenance:** Each model file — including the rebuilt exterior shell `public/Duramax_LLY_2005_66L_V8.glb` — lists what reference it was built from and whether each system/feature and dimension is `sourced`/`verified` or `illustrative`.

### M12 scene-placed cosmetic add-on (D-038 extension)

The LLY intake cover (`public/models/intake_cover_lly.glb`) uses the scene-placed class with these additions: one contract **root Group** `intake_cover_lly` (a deliberate extension of the M8 single-root-mesh rule, needed for two material-separated meshes); two mesh leaves `ext_intake_cover_body` / `ext_intake_cover_lettering`; `if_intake_cover_rear_bolt` / `if_intake_cover_duct_clamp` empty markers; no pivot/animation; project-frame authoring at final positions; untextured `MeshStandardMaterial` (≤ 2 materials, no images/textures/UVs); total triangle cap 1,800 (body ≤ 1,200, lettering ≤ 600); file-size cap 64 KiB (65,536 B). It is loaded through `loadVariantScene` and registered as a static section-cap source; it is not a catalog variant and does not add a slot.

### M13 part-local internal variant (D-048)

`public/models/variants/rot_conrod_c1_forged.glb` is a second **part-local** drop-in (after M8 `rot_piston_c1_lowcomp.glb`): contract root `rot_conrod_c1_forged`, child `rot_conrod_smallend_c1_forged` at `(0, 0, 163.0) mm`, origin at the big-end bore axis, three untextured `MeshStandardMaterial`s, no `if_*` markers, indexed `POSITION` + `NORMAL` triangles only, **≤ 1,400 triangles**, **≤ 48 KiB**. It is loaded through the existing `extractAllPartPrimitives` path and swapped into the eight instanced conrod slots; it adds no asset class, no pivot and no animation.
